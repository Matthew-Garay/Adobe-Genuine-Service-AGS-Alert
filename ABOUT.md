# Adobe Genuine Service AGS - Repositorio de Soporte

## Acerca de

Repositorio interno de documentacion y archivos de respaldo relacionados con el servicio de autenticacion genuina de Adobe (AGS) y la gestion de instalaciones de productos Adobe en entornos Windows. Centraliza rutas de instalacion, directorios de productos y scripts de configuracion para el bloqueo o deshabilitacion de servicios como AGSService y AdobeGCClient. Es un repositorio de documentacion y almacenamiento de archivos grandes mediante Git LFS, sin componentes de ejecucion ni logica de negocio.

## Caracteristicas principales

- Almacenamiento de archivos grandes mediante Git LFS (supera el limite de 100 MB por archivo en GitHub).
- Scripts de PowerShell para bloquear o deshabilitar servicios de Adobe y tareas programadas asociadas.
- Documentacion de rutas de instalacion y directorios de productos Adobe.
- Sin base de datos, concurrencia, procesamiento en tiempo real ni protocolos de red propios.

## Stack tecnologico

| Categoria | Tecnologia |
|-----------|------------|
| Control de versiones | Git 2.0 o superior |
| Almacenamiento de archivos | Git LFS (Large File Storage) |
| Scripts | PowerShell |
| Sistema operativo objetivo | Windows |
