# Rutas de instalación y directorios de Adobe
# Repositorio: Adobe Genuine Service (AGS) - Soporte

## Rutas predeterminadas en Windows

### Adobe Creative Cloud
C:\Program Files\Adobe\Adobe Creative Cloud\

### Adobe Acrobat Professional 2020
C:\Program Files\Adobe\Acrobat 2020\Acrobat\

### Adobe Genuine Service (AGS)
C:\Program Files\Common Files\Adobe\Adobe Desktop Common\AGS\
C:\ProgramData\Adobe\SLStore\
C:\ProgramData\Adobe\Adobe PCD\

### Archivos de usuario y configuración
%APPDATA%\Adobe\
%LOCALAPPDATA%\Adobe\
%PROGRAMDATA%\Adobe\

## Archivos y carpetas relevantes

| Archivo/Carpeta | Ruta típica | Descripción |
|-----------------|-------------|-------------|
| Adobe Genuine Service | C:\Program Files\Common Files\Adobe\AGS\ | Servicio de autenticación genuina de Adobe |
| SLStore | C:\ProgramData\Adobe\SLStore\ | Almacenamiento de licencias de software |
| Adobe PCD | C:\ProgramData\Adobe\Adobe PCD\ | Datos de productos de Adobe |
| Logs de AGS | C:\ProgramData\Adobe\AGS\logs\ | Registros del servicio genuino |
| Creative Cloud | C:\Program Files\Adobe\Creative Cloud\ | Aplicación de escritorio de Adobe |

## Cómo localizar rutas de instalación

1. Abre el Símbolo del sistema (CMD) o PowerShell.
2. Ejecuta: `reg query "HKLM\SOFTWARE\Adobe"` para ver claves de registro.
3. O revisa: `C:\Program Files\Adobe\` y `C:\Program Files (x86)\Adobe\`.

## Notas importantes

- Algunas rutas requieren permisos de administrador para acceder.
- Las rutas pueden variar según la versión del producto y el idioma de instalación.
- No elimines ni modifiques archivos de AGS sin comprender las consecuencias, ya que puede afectar la activación de productos Adobe.
